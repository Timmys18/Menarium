# Menarium: обновление сайта (простой процесс)

Нужно сделать так, чтобы после твоих изменений в Cursor код попал в GitHub, а затем production-сервер обновился одной командой.

Если хочешь максимально просто (одной командой):

## ВАРИАНТ С ОДНОЙ КОМАНДОЙ

1. Открой PowerShell в папке проекта.
2. Запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-prod.ps1 -ServerIp ТВОЙ_IP
```

Сервер и папку проекта можно не указывать, если совпадает с настройками:
- папка проекта на сервере: `/var/www/menarium`

## ШАГ 1 — после изменений в Cursor

1. Открой PowerShell в папке проекта.
2. Запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish.ps1
```

Если консоль напишет “Нечего коммитить — изменений нет”, значит отправлять нечего.

## ШАГ 2 — зайти на сервер

Выполни команду:

```bash
ssh root@ТВОЙ_IP
```

## ШАГ 3 — обновить сайт

1. Перейди в папку проекта на сервере (ту же, где есть `package.json`).
2. Запусти:

```bash
bash scripts/redeploy.sh
```

## ШАГ 4 — проверить

Открой в браузере:

`https://menarium.ru`

Проверь:
- работает регистрация
- открывается каталог
- открываются страницы объявлений и обмен

## Если что-то пошло не так (самое простое)

### 1) На сервере есть локальные изменения

Если `git pull` ругается и говорит, что есть “локальные изменения”, сделай так:

```bash
git status
git reset --hard
git clean -fd
bash scripts/redeploy.sh
```

Важно: `reset --hard` удаляет локальные изменения на сервере.

### 2) `git pull` не проходит

1. Открой текст ошибки в терминале.
2. Выполни:

```bash
git status
```

И повтори `bash scripts/redeploy.sh`.

Если снова не проходит, пришли текст ошибки администратору (там обычно написано, что мешает).

### 3) `npm run build` падает

1. Открой ошибки сборки в терминале (они будут выше).
2. После исправления повтори:

```bash
bash scripts/redeploy.sh
```

Если сборка падает после обновления и ничего менять не нужно, можно откатиться на предыдущую версию:

```bash
git reset --hard HEAD~1
bash scripts/redeploy.sh
```
