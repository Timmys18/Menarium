# Menarium: настройка PostgreSQL в Yandex Cloud (просто)

## 1) Создай базу в Yandex Cloud

1. Открой Yandex Cloud.
2. Перейди в раздел **Managed Service for PostgreSQL**.
3. Нажми **Создать кластер**.
4. Выбери регион в РФ.
5. Задай:
   - имя кластера
   - имя базы: `menarium_db`
   - пользователя и пароль
6. Нажми **Создать**.

## 2) Возьми строку подключения

1. Открой созданный кластер.
2. Найди раздел с параметрами подключения.
3. Скопируй хост, порт, имя базы, пользователя и пароль.

## 3) Заполни `.env.production`

На сервере в файле `.env.production` заполни:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:6432/menarium_db?schema=public&sslmode=require
```

Замени:
- `USER` на имя пользователя
- `PASSWORD` на пароль
- `HOST` на адрес хоста кластера

## 4) Применить таблицы в базе

После заполнения `.env.production` запусти деплой-скрипт:

```bash
bash scripts/deploy-vm.sh
```

Скрипт сам применит миграции базы.

## Проверка

Если всё хорошо, ошибок про базу нет, и сайт открывается.
