# Menarium

## Как запустить проект локально

1. Установите зависимости:

```bash
npm install
```

2. Сгенерируйте Prisma Client:

```bash
npx prisma generate
```

3. Примените миграции базы данных (по умолчанию используется SQLite через Prisma):

```bash
npx prisma migrate dev
```

4. Запустите dev-сервер:

```bash
npm run dev
```

После этого приложение будет доступно по адресу `http://localhost:3000`.

### Обязательные переменные окружения

Создайте файл `.env` в корне проекта и укажите необходимые переменные (без реальных значений):

```env
DATABASE_URL=...        # строка подключения Prisma (SQLite или другая БД)
NEXTAUTH_URL=...        # базовый URL приложения, например http://localhost:3000
NEXTAUTH_SECRET=...     # секрет для NextAuth
```

## Smoke-тесты (Playwright)

Для запуска простого smoke-контра используйте:

```bash
npm run test:smoke
```

Тесты открывают главную страницу (`/`) и каталог (`/catalog`), проверяя, что страница не пустая и отображает базовые элементы либо пустое состояние каталога.
